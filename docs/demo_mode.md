# Demo Mode

Demo Mode is a deterministic, offline product walkthrough. It requires zero API keys, network inference, and provider quota.

The bundled PID Control flow follows the real user experience: choose a module, preview the study pack, run once, see understandable stages, and browse all results in My Materials. Repeated Run clicks and reruns resolve to the same logical command and run.

Demo Mode cannot enable providers, increase budgets, approve retries, promote manifests, change source authority, migrate legacy data, restore backups, or perform database recovery. Demo content is clearly labeled and must not be represented as a live AI result.
