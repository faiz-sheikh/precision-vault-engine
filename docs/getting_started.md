# Getting started with Precision Vault Engine

Precision Vault Engine (PVE) creates, checks, preserves, and organizes study material. Its student interface explains each action before it runs, and Demo Mode works without API keys or network inference.

## First launch

1. Start the dashboard with `streamlit run pve/dashboard.py`.
2. Follow the five short welcome steps.
3. Choose **Demo**, then **Try Demo Study Pack**.
4. Review the PID Control plan and select **Run this plan**.
5. Open **My Materials** to read the notes, quiz, viva practice, revision sheet, research, and flashcards.

Every demo result is marked **DEMO OUTPUT** and states that no external AI provider was contacted.

For a terminal-only check, use `pve doctor`. Run `pve demo` to create the same bundled study pack offline.
